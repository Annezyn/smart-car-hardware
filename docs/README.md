# 文档说明

## 如何查看和修改设计

1. 使用 EasyEDA 打开根目录中对应模块的 `.epro2` 文件。
2. 修改原理图或 PCB 后，执行设计规则检查，并重新导出制板文件和 BOM。
3. 将更新后的资料与源工程保持同名，例如 `主板.epro2`、`主板.zip`、`主板.xlsx`。

## 制板文件内容

制板压缩包通常包含以下内容：

- Gerber 层文件：铜层、阻焊层、丝印层、外形层等；
- 钻孔文件：金属化孔、非金属化孔及过孔钻孔；
- 飞针测试数据或其他下单辅助文件；
- PCB 下单说明。

将压缩包直接上传至制板平台即可识别。下单前请在平台预览板框、层数、阻焊和丝印，并确认生产参数与设计要求一致。

## BOM 使用说明

每个 `.xlsx` 文件是对应模块的 BOM。采购或贴装前，应重点核对：位号、元件名称/参数、封装、数量和替代料。若更改了元件型号或封装，必须同步更新 BOM 和 PCB。

## 版本管理约定

后续每次可生产的硬件修改都应：

1. 更新源工程、制板压缩包和 BOM；
2. 在 `docs/CHANGELOG.md` 中说明改动；
3. 使用 Git 标签标记可打样或可量产版本。
